# Book612 플레이스토어 등록 순서 (2026-10-18)

BARAM과 같은 방법: **웹앱(booktrack.pages.dev)을 PWABuilder로 감싼 안드로이드 앱(TWA)**.
웹 코드를 고치면 앱에도 바로 반영된다. 앱 이름·아이콘·패키지를 바꿀 때만 새 .aab를 만든다.

## BARAM에서 배운 것 (꼭 지킬 것)
1. **Play 앱 서명 키 지문**까지 `assetlinks.json`에 넣어야 앱이 주소창 없이 열린다(BARAM은 빠져서 주소창이 보였음).
2. **테스터 12명이 14일 동안 '실제로' 써야** 한다. BARAM은 설치만 하고 안 열어서(하루 사용자 0~4명) 2026-10-13 "추가 테스트 필요"로 거절됨.
   → 테스터에게 **매일(최소 이틀에 한 번) 열어서 책 하나·밑줄 하나** 부탁. 테스트 중 **새 버전을 2번** 올리고, 비공개 의견을 받는다.
3. PWABuilder 옵션의 버전 칸은 매번 1.0.0.0 / 1로 돌아가 있으니 **직접 올려 적는다**.
4. **서명 키 파일(signing.keystore, signing-key-info.txt)은 절대 잃어버리면 안 되고**, 프로젝트 폴더·GitHub에 넣지 않는다. Claude도 읽지 않는다.

## 형이 할 일 (순서대로)

### 1. Play Console에서 새 앱 만들기
- https://play.google.com/console → 앱 만들기
- 앱 이름 `Book612 – 책과 길들인 문장` / 기본 언어 한국어 / 앱 / 무료 → 약관 동의(형이 직접)

### 2. PWABuilder로 앱 파일(.aab) 만들기
- https://www.pwabuilder.com → 주소 `https://booktrack.pages.dev` → Start → **Package for stores → Android → Generate Package**
- Options(직접 확인·입력):
  - Package ID: `dev.pages.booktrack.twa` (**한번 정하면 못 바꿈**)
  - App name: `Book612 – 책과 길들인 문장` / Launcher name: `Book612`
  - App version: `1.0.0` / Version code: `1`
  - Theme color `#f5eedc`, Background color `#f5eedc`, Nav color `#f5eedc`
  - Signing key: **Create new** (새 앱이라 새 키). 이름·회사 칸은 형 이름으로
- 내려받은 zip 안: `.aab`(올릴 파일), `.apk`(폰 시험용), `assetlinks.json`, **signing.keystore / signing-key-info.txt(안전한 곳에 보관)**
- zip은 `다운로드\Book612 - Google Play package` 같은 이름으로 두고, 키 두 파일은 따로 백업(USB·클라우드 개인 폴더)

### 3. assetlinks.json 넘겨주기
- zip 안의 `assetlinks.json` **내용만** Claude에게 보여 주기(지문만 들어 있는 공개용 파일이라 괜찮음. 키 파일은 보여 주지 않기)
- Claude가 `public/.well-known/assetlinks.json`으로 올림 → 미리보기 → 실제 사이트

### 4. 비공개 테스트에 올리기
- Play Console → 테스트 → 비공개 테스트 → 트랙 만들기 → 테스터(이메일 목록 또는 Google 그룹) 12명 이상
- 새 버전 만들기 → `.aab` 올리기 → 출시 노트 → 국가: 대한민국 → 검토 보내기
- 첫 업로드 뒤: **설정 → 앱 무결성 → Play 앱 서명**의 **SHA-256 지문**을 Claude에게 알려 주기 → assetlinks.json에 추가(BARAM 교훈 1)

### 5. 앱 콘텐츠·스토어 등록정보 채우기
- `스토어-등록정보.md`를 보며 붙여 넣기(설명, 그래픽, 개인정보처리방침, 데이터 보안, 콘텐츠 등급, 타겟층)

### 6. 14일 테스트 → 프로덕션 신청
- 테스터 모집 문구: `테스터-모집-카톡.md`
- 대시보드의 "n일 동안 참여한 테스터 12명"이 14일이 되면 프로덕션 신청. 신청 뒤 승인 메일까지 테스터에게 앱을 지우지 말라고 안내.

## Claude가 이미 해 둔 것 (2026-10-18)
- 개인정보처리방침 `public/privacy.html` (https://booktrack.pages.dev/privacy), 앱 조종사 화면 맨 아래에 링크
- manifest 보강(id, 방향, 언어, 분류, 192 maskable 아이콘), 서비스 워커 v9
- 스토어 그래픽: 아이콘 512, 대표 그래픽 1024×500, 스크린샷 6장(가상 책으로 찍음)
- 등록정보 글, 데이터 보안·콘텐츠 등급 답변 초안, 테스터 모집 문구
